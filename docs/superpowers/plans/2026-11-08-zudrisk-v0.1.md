# ZudRisk v0.1 (keyless hindcast) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compute a soum-level dzud risk score for winter 2023/24 from keyless public data (NASA POWER winter cold + NSO grazing pressure), validate it against NSO 2024 adult losses, and show it on a static map page.

**Architecture:** One small Python module per source or step under `pipeline/`. Each step reads from `data/` and writes to `data/`, so steps rerun independently. Pure functions (score, Spearman, name normalisation) carry `--check` self-tests. `pipeline/export.py` writes one simplified GeoJSON and one validation JSON into `site/data/`. A single Leaflet page draws them over OSM tiles.

**Tech Stack:**
- Python ≥ 3.12 via `uv`, with `shapely` 2.x and `numpy` (both approved in the spec) and stdlib `urllib`/`json`/`csv`/`zipfile`.
- Leaflet 1.9.4 from unpkg, OSM raster tiles.

**Spec:** `docs/superpowers/specs/2026-11-08-zudrisk-design.md`. Evidence: `docs/research/data-sources.md`.

## Global Constraints

- No credentials anywhere in the repo. `.gitignore` covers `.env`, `*.netrc`, `*credentials*`, `*service-account*.json` and `data/raw/`.
- Dependencies: `shapely` and `numpy` only. No `requests`, `pandas`, `geopandas`, `scipy` or `pytest`.
- Winter `W = Y/Y+1`. Cold = mean of monthly T2M for Nov Y, Dec Y, Jan Y+1, Feb Y+1. Baseline = winters 2001/02 … 2020/21 (20 winters).
- Sheep units: camel 5, horse 7, cattle 6, sheep 1, goat 0.9.
- Weights: snow 0.41, cold 0.35, pressure 0.29, summer 0.24. v0.1 uses cold and pressure only: `risk = (0.35·z_cold + 0.29·z_pressure) / 0.64`.
- z clipped to ±3. Class cuts on the weighted mean z: `< −1.0` very low, `[−1.0, −0.5)` low, `[−0.5, 0.5)` medium, `[0.5, 1.0)` high, `≥ 1.0` very high.
- Mortality for winter Y/Y+1 = losses in year Y+1 ÷ stock in year Y, both in sheep units.
- Ulaanbaatar soums (`adm1_pcode == "MN11"`, 9 units) are drawn grey and excluded from scoring and validation.
- Every indicator function takes `as_of: date`, default 31 March of Y+1. A month counts only if its last day ≤ `as_of`.
- Site text in Mongolian (Cyrillic) and English, with a toggle. It attributes OSM (ODbL), OCHA COD-AB (CC BY-IGO), NASA POWER and NSO Mongolia.
- No pass bar on validation: report the numbers whatever they are.

## Data endpoints (checked live 2026-11-08)

- **Soums:** OCHA COD-AB GeoJSON zip, `https://data.humdata.org/dataset/a9b0a8a6-cb14-448e-b35c-aa5eb51b0557/resource/de6b11d3-767d-449f-99fc-80c5b4e9abe3/download/mng_admin_boundaries.geojson.zip`. Inside is `mng_admin2.geojson`: 339 `Polygon` features with fields `adm2_pcode`, `adm2_name` (Latin), `adm2_name1` (Cyrillic), `adm1_pcode`, `adm1_name`, `adm1_name1`, `area_sqkm`.
- **NSO PxWeb:** `https://data.1212.mn/api/v1/en/NSO/Industry,%20service/Livestock/<table>`.
  - Tables: `DT_NSO_1001_021V1.px` (stock) and `DT_NSO_1001_029V1.px` (adult losses).
  - `GET` returns metadata. Its variables are `Малын төрөл` (Type of livestock: `0` Total, `1` Horse, `2` Cattle, `3` Camel, `4` Sheep, `5` Goat), `Бүс` (Region: 3-digit aimag, 5-digit soum) and `Он` (Year, index codes mapped by `valueTexts`, e.g. `"1"` → `"2024"`).
  - `POST` body: `{"query":[{"code":"Бүс","selection":{"filter":"item","values":[...]}},{"code":"Он","selection":{"filter":"item","values":[...]}}],"response":{"format":"json"}}`.
  - It returns `data: [{"key":[type, region, year], "values":["54.737"]}]`. Values are thousand head (inferred); `".."` means missing.
  - Region names in `021`'s metadata are Cyrillic. Use them for the join.
- **NASA POWER:** `https://power.larc.nasa.gov/api/temporal/monthly/regional?latitude-min=..&latitude-max=..&longitude-min=..&longitude-max=..&parameters=T2M&community=AG&start=2001&end=2024&format=JSON`.
  - Each box is at most 10° × 10°. One 10° × 10° box returns 336 point features (0.5° lat × 0.625° lon) in about 2 s.
  - `properties.parameter.T2M` keys are `"YYYYMM"`, plus `"YYYY13"` for the annual mean (ignore it). `-999` is the fill value.
  - Boxes: lat [41.5, 51.5] and [51.5, 52.5] × lon [87, 97], [97, 107], [107, 117], [117, 120]. That is 8 requests. Points on shared edges repeat, so dedupe them by (lon, lat).
- **Join (measured).** Normalise names with: lowercase; `ё→е`; strip a trailing ` сум`; `гөвь→говь`; remove spaces and hyphens. Then match (aimag, soum).
  - Result: all 339 COD soums match.
  - NSO has exactly 2 leftover soums, `18340` (Баян-Өлгий / Цагааннуур) and `26770` (Хөвсгөл / Хатгал). They are newer soums absent from the 2020 boundaries. Drop them and report them.

## File structure

```
pyproject.toml            uv project; deps shapely, numpy
.gitignore
pipeline/__init__.py      empty
pipeline/http.py          get_json(url) / post_json(url, body): urllib, retry on 429/5xx (3 tries, 5 s backoff)
pipeline/boundaries.py    download COD zip → data/raw/; write data/derived/soums.geojson (339 features, trimmed props)
pipeline/nso.py           name normaliser, crosswalk, fetch stock + losses → data/derived/livestock.csv
pipeline/power.py         fetch 8 POWER boxes → data/raw/power_t2m.json; soum→cell map → data/derived/soum_cells.json
pipeline/indicators.py    cold() and pressure() → data/derived/indicators_<winter>.csv
pipeline/score.py         z clip, weighted mean, classes (pure)
pipeline/validate.py      mortality, spearman, top-quintile hit rate → data/derived/validation_<winter>.json
pipeline/export.py        join everything → site/data/risk_<winter>.geojson (simplified) + site/data/validation_<winter>.json
site/index.html           page shell, legend, panels, mn/en text
site/app.js               load data, draw choropleth, popup, language toggle
README.md                 one paragraph + the run commands below
```

Run order: `boundaries → nso → power → indicators → validate → export`. Every module runs as `uv run python -m pipeline.<name> [--winter 2023]`, and `--check` runs its self-test without network.

## Review Focus

1. **NSO `".."` cells**, and soums missing in a year: the soum is dropped from that winter's validation and counted in `n_dropped`, and nothing crashes. Covered by a `nso` and a `validate` check.
2. **POWER `-999`** in a month: that month is treated as missing. If any of the 4 winter months is missing, the cold value is `None` and the soum is unscored for cold. Covered by an `indicators` check.
3. **A soum with no POWER point inside its polygon** (small soums): it takes the nearest point to its `representative_point()`. Covered by a `power` check.
4. **Duplicate POWER points on box seams:** deduped by (lon, lat). Covered by a `power` check.
5. **A soum with stock 0 or missing** (no division by zero in mortality or log density): excluded and counted. Covered by a `validate` and an `indicators` check.

### Task 5: Indicators and score

**Files:**
- Create: `pipeline/score.py`, `pipeline/indicators.py`

**Interfaces:**
- Produces in `pipeline/score.py`:
  - `WEIGHTS = {"snow": 0.41, "cold": 0.35, "pressure": 0.29, "summer": 0.24}`.
  - `zscore(x: float, baseline: list[float]) -> float`: clipped to ±3. Returns `None` if there are fewer than 10 baseline values or the std is 0.
  - `risk(z: dict[str, float | None]) -> float | None`: the weighted mean over the non-None indicators. Returns `None` if all are None.
  - `risk_class(r: float) -> int`: 0 to 4, using the global cuts.
- Produces in `pipeline/indicators.py`:
  - `winter_months(year: int, as_of: date) -> list[str]`: `"YYYYMM"` for Nov Y, Dec Y, Jan Y+1 and Feb Y+1 whose month end ≤ `as_of`.
  - `cold(pcode, year, as_of) -> float | None`: the mean T2M over the soum's cells and the winter months; `None` if any month is missing.
  - `pressure_raw(pcode, year) -> float | None`: `log(stock sheep units × 1000 / area_km2)`.
  - `main(year)` writes `data/derived/indicators_<year>.csv` with columns `pcode, cold_c, z_cold, su_per_km2, z_pressure, risk, risk_class`.
    - `z_cold = −zscore(cold(year), [cold(b) for b in 2001..2020])`, so colder means a higher z.
    - `z_pressure = zscore(pressure_raw(year), [pressure_raw of all scored soums that year])`.
    - UB soums are skipped.

- [ ] **Step 1: Write the checks.**
  - `zscore(12, [10]*5 + [12]*5) == 1.0`: population std (ddof = 0), so mean 11 and std 1.
  - `zscore(20, [10]*5 + [12]*5) == 3.0`: clipped.
  - `risk({"cold": 1.0, "pressure": 0.0, "snow": None, "summer": None}) == 0.35/0.64`.
  - `risk_class` gives 0, 1, 2, 3, 4 for −1.2, −0.7, 0.0, 0.7 and 1.2, and gives 3 at exactly 0.5 and 4 at exactly 1.0.
  - `winter_months(2023, date(2024, 1, 15)) == ["202311", "202312"]`.
  - `cold` with one `-999`-dropped month returns `None`.
  - A soum with stock 0 gets `pressure_raw is None`.
- [ ] **Step 2:** Run `uv run python -m pipeline.score --check && uv run python -m pipeline.indicators --check`. Expected: FAIL.
- [ ] **Step 3:** Implement.
- [ ] **Step 4:** Run the checks (PASS), then `uv run python -m pipeline.indicators --winter 2023`. Expected output: `330 scored, 9 UB skipped` (or fewer scored, with a count of unscored and the reason for each), and the class histogram.
- [ ] **Step 5:** Commit `pipeline/score.py`, `pipeline/indicators.py` and `data/derived/indicators_2023.csv`.

### Task 6: Validation

**Files:**
- Create: `pipeline/validate.py`

**Interfaces:**
- Consumes: `load_livestock()`, `sheep_units()`, and `data/derived/indicators_<year>.csv`.
- Produces: `spearman(x: list[float], y: list[float]) -> float`. It ranks with average ties, then takes the Pearson of the ranks with numpy.
- Produces: `mortality(pcode, year) -> float | None`: loss SU in Y+1 ÷ stock SU in Y. `None` if either is missing or stock is 0.
- Produces: `top_quintile_hit(risk, mort) -> float`: the share of the top-20 % risk soums that are also in the top-20 % mortality soums.
- Produces: `data/derived/validation_<year>.json` with fields `winter`, `n`, `n_dropped`, `dropped_reasons`, `spearman_soum`, `spearman_aimag`, `top_quintile_hit`, `national_mortality_pct`, `indicators_used: ["cold", "pressure"]`.
  - Aimag values are herd-weighted means of soum risk against aimag mortality, computed from summed soum SU.

- [ ] **Step 1: Write the checks.**
  - `spearman([1,2,3,4], [10,20,30,40]) == 1.0`.
  - `spearman([1,2,3,4], [4,3,2,1]) == -1.0`.
  - With ties, `spearman([1,1,2], [1,2,3])` is about `0.866` to 3 decimals.
  - `mortality` with stock 0 returns `None`, and that soum is counted in `n_dropped`.
- [ ] **Step 2:** Run `--check`. Expected: FAIL.
- [ ] **Step 3:** Implement.
- [ ] **Step 4:** Run `--check` (PASS), then `uv run python -m pipeline.validate --winter 2023`. - More winters and the pooled ρ; excess mortality, which needs several scored winters and the normal-winter rule (v0.2).
- A winter selector on the site (v0.2).
- As-of outlook runs (v0.4). The `as_of` parameter already exists from Task 5.
